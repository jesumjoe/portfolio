# Personal Portfolio

This is a personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Project Info

This project showcases projects, skills, and contact information.

## Getting Started

1.  **Clone the repository:**
    ```sh
    git clone <YOUR_GIT_URL>
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Run the development server:**
    ```sh
    npm run dev
    ```

## Technologies Used

-   Vite
-   TypeScript
-   React
-   shadcn-ui
-   Tailwind CSS
